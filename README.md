# Uni Seeburg MBA 2026 LIT-01

Temporär öffentliches Bootstrap-Repo für eine theoretische bzw. Literaturarbeit mit konzeptionellem Framework und optionaler explorativer Validierung.

Dieses Repo enthält absichtlich keine personenbezogenen Daten, keinen konkreten Arbeitstitel, keine privaten Mails, keine Formulare, keine Lernplattform-Volltexte und keine Rohdaten. Es ist nur die öffentliche Arbeitsstruktur für Agenten.

## Arbeitslogik

1. `docs/00-publication-boundary.md` lesen.
2. `docs/01-12-schritte-outline-gate.md` lesen.
3. `workspace/01_expose_und_forschungsfrage/OUTLINE.md` stabilisieren.
4. Erst danach Literaturmatrix, Syntheselogik und optionale explorative Anwendung vertiefen.

## Aktueller Typ

- Arbeitstyp: Literaturarbeit / konzeptionelles Framework.
- Primärer Qualitätsfokus: Reviewfrage, Suchstrategie, Quellenqualität, Framework-Eigenleistung, kritische Reflexion.
- Public-Grenze: konkrete Person, Thema, Unternehmensdaten und Plattform-/Prompt-Rohdaten bleiben außerhalb dieses öffentlichen Repos.

## Wichtig

Nach Umstellung auf private Sichtbarkeit kann der private Agentenkontext importiert werden. Bis dahin nur Platzhalter und generische Struktur verwenden.
